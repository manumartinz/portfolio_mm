# portfolio_mm

CV / portfolio personal de Manuel A. Martínez — Frontend Developer.

Sitio estático (HTML + CSS, sin build). Para verlo, abrir `index.html` en el navegador.

- Responsive.
- Proyectos: las imágenes van en `assets/projects/`. Usar screenshots en 16:10
  (1440×900, o 2880×1800 para retina), en `.webp` o `.png`. Se recortan desde
  arriba, así que lo importante tiene que quedar en la parte superior.
- Imprimible: `Ctrl + P` genera una versión limpia del CV en PDF.
